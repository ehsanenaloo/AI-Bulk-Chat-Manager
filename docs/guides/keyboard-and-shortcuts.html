The global shortcut#

The extension has one shortcut, set up through your browser.

ActionDefault key
Open or close the panel (start or finish selecting)Alt+Shift+B
  • It works on ChatGPT, Claude, Gemini and Grok. On any other page it does nothing.
  • It works in a tab that was open before you installed the extension. The extension attaches itself to the tab first.
  • While a run is going, pressing it to finish does not close the panel. The panel tells you to Stop the running action first.
  • On a Mac, Alt is the Option key.

Change the shortcut#

  1. Open the Options page and go to Keyboard shortcut.
  2. Click Change shortcut. Your browser’s shortcut page opens: chrome://extensions/shortcuts in Chrome, edge://extensions/shortcuts in Edge, and the Add-ons manager in Firefox (about:addons).
  3. Find Open or close the selection panel under AI Bulk Chat Manager and set your key.

If the Options page shows Not set, the default key was probably taken by another extension or by the browser. Set a key in the same place. Some browsers block a link to their own pages. If that happens, the Options page tells you where to go by hand.

Inside the panel#

KeyWhat it does
Tab and Shift+TabMove between the panel’s buttons and boxes.
Enter or SpacePress the focused button.
Enter in Part of a chat titleRuns Select for that text.
Esc with the Export menu openCloses the menu and returns to Export.
Shift + click on a chatTicks every shown chat between it and the last one you ticked.

Keys you type in the panel do not reach the site, so they do not trigger the site’s own shortcuts.

Inside the confirmation dialog#

KeyWhat it does
EscCloses the dialog without doing anything.
Tab and Shift+TabMove around inside the dialog. The focus does not leave it.
Enter when it opensPresses Cancel, because Cancel has the focus. To confirm, move to the red button or click it.

In the toolbar popup#

The popup has no shortcuts of its own. Use Tab and Enter like on any page. It shows the current shortcut under the main button.
