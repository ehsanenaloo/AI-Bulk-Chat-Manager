Works on: desktop Chrome and other Chromium browsers (Chrome 111 or newer), Microsoft Edge, and Firefox 140 or newer. Chrome and Edge use the same package.

Works with: ChatGPT, Claude, Gemini and Grok, on these addresses only: chatgpt.com, chat.openai.com, claude.ai, gemini.google.com and grok.com.

Chrome and other Chromium browsers#

  1. Open the Chrome Web Store page.
  2. Click Add to Chrome and confirm.
  3. Click the Extensions (puzzle piece) button in the toolbar and pin AI Bulk Chat Manager.

Brave, Opera, Vivaldi and other Chromium browsers that install Chrome extensions use the same page.

Microsoft Edge#

Edge can install extensions from the Chrome Web Store.

  1. Open the Chrome Web Store page in Edge.
  2. If Edge shows a banner, choose Allow extensions from other stores.
  3. Click Add to Chrome and confirm.

Or load the Chrome package from the latest release: unzip ai-bulk-chat-manager-<version>.zip, open edge://extensions, turn on Developer mode, click Load unpacked and choose the unzipped folder.

Firefox#

Firefox needs version 140 or newer, on desktop. Until the extension is listed on Firefox Add-ons, load the release package as a temporary add-on.

  1. Download ai-bulk-chat-manager-<version>-firefox.zip from the latest release.
  2. Type about:debugging in the address bar and open This Firefox.
  3. Click Load Temporary Add-on and choose the zip file.
Temporary means temporary

Firefox removes a temporary add-on when you close the browser, so you repeat these steps next time. A listing on Firefox Add-ons would not have this limit.

Firefox asks for access to the five chat sites when you add the extension. That access is what lets it add checkboxes to the chat list. See Privacy and permissions. If you decline it, the extension cannot work on those sites.

From source#

You can run the extension straight from the source code.

  1. Download or clone the repository.
  2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  3. Click Load unpacked and choose the extension folder.

For Firefox, build the Firefox package first, because Firefox needs a slightly different manifest. With Node.js installed, run this in the repository folder, then load dist/ai-bulk-chat-manager-<version>-firefox.zip as shown above.

node scripts/build.mjs --firefox

A copy loaded from source has a different extension identity from the store version. Both can be installed side by side.

First run: tabs that were already open#

Browsers add an extension to a page only when the page loads after the install. A chat tab that was open before you installed has no extension in it yet.

You do not need to reload. Open that tab and click the toolbar icon (or press Alt+Shift+B). The extension attaches itself to the tab and starts. If it cannot, the popup says Can’t reach the site and offers Reload page.

Check that it works#

  1. Open one of the chat sites and sign in.
  2. Click the toolbar icon. The status card should say Ready on followed by the site name.
  3. Click Start selecting chats. Checkboxes appear in the sidebar and the panel opens.

If something differs, see Troubleshooting.

Updating and removing#

Store versions update through your browser, which checks for new versions by itself. A copy loaded from source or as a temporary add-on does not update itself. Load the newer files again.

To remove it, use your browser’s extensions page. Removing the extension also removes the settings it stored. Files you exported stay in your downloads folder until you delete them.
