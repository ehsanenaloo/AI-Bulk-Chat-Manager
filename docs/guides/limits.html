This page is the honest list. It is better to know these before a big clean-up than after.

Deleting cannot be undone#

When the extension deletes a chat, the site deletes it. There is no recycle bin and no undo, in the extension or, in general, on the sites. Archived ChatGPT chats can be restored from ChatGPT. Deleted chats generally cannot. The confirmation dialog, the extra tick for big deletes and Export exist for this reason. Use them.

The sites change, and then things can break#

This is an independent project. The four sites do not work with it and do not promise to keep their pages the same. It reads each site’s page the way you see it, and it uses the same internal requests that the site’s own buttons use. The sites do not document those, and they change them without notice.

When a site redesigns its sidebar or its menus, one of these can stop working until the extension is updated:

  • checkboxes appear on the wrong things, or not at all;
  • Select all or Load all older chats finds no chats or too few;
  • Delete or Archive fails, with a reason on the result screen;
  • the page-menu route cannot find a button or a menu item.

The extension is built to fail safely. If it cannot find the right button, it stops and reports a failure rather than guess. It counts a delete as done only after the chat is really gone from the list. Failed chats stay selected so nothing is lost track of.

What was checked for version 9.0.0

The sidebar of Claude was checked against the real site on 2026-10-08. The pages of ChatGPT, Gemini and Grok could not be checked against the real sites for this release. For those three, the code was tested against test copies of the sites, and the approach is carried over from version 8, which real people used. So there is a higher chance that one of them has changed since. If something fails, update the extension, try turning Fast mode off, and report it. Reports are the fastest way to get a site fixed.

Archive is for ChatGPT only#

The other sites do not offer archiving, so the extension does not either. The button is hidden there.

Fast mode uses undocumented requests#

Fast mode depends on the sites’ internal requests. They can change or be refused. The extension then falls back to the page menus for the chats that failed. The page-menu route is slower, and depends on the site’s menus. If both fail, the chat is reported as failed.

Very long histories need loading first#

The sites load chats a page at a time. The extension can only select what is in the page. For a long history, click Load all older chats before Select all or Oldest. Loading takes longer the more chats you have, and you can stop it at any time.

The chat list must be visible#

If the sidebar is closed, collapsed or hidden by a small window, the extension sees no chats and the panel says so. Open the sidebar. Chats in collapsed parts of the list are not selected by Select all.

Claude’s Recents page has its own selection#

Claude has a Recents page with checkboxes and a delete button built into the site. They are Claude’s own tools. This extension works on the chat list in the sidebar.

Tabs open before the install#

A chat tab that was open when you installed or updated the extension has no extension in it yet. Click the toolbar icon (or use the shortcut) and the extension attaches itself. If it cannot, reload the tab. See Installation.

Firefox#

Firefox needs version 140 or newer, on desktop. Firefox asks for access to the five chat sites when you add the extension, and the extension cannot work without it. A temporary add-on is removed when Firefox closes.

Other limits#

  • It works only on chatgpt.com, chat.openai.com, claude.ai, gemini.google.com and grok.com.
  • It is built for desktop browsers.
  • The selection exists only in the open page. Reloading the tab loses it.
  • Export is a list of titles and links, not a backup of conversations.
  • It handles chats in the sidebar list. It does not manage projects, folders, shared links or other site features.
  • While a run is going, keep the tab open. Closing it ends the run, and the chats not yet handled stay as they were.
