Reports are public on GitHub. Write them so they help the developer without exposing anything private.

Before you report#

  1. Update the extension to the latest version. Check the version in the popup header.
  2. Reload the chat page and try again.
  3. If a delete or archive failed, turn Fast mode off and retry. Note whether that changed anything.
  4. Look at Troubleshooting and Limits.

Choose the right form#

All forms are on one page: github.com/ehsanenaloo/AI-Bulk-Chat-Manager/issues/new/choose. You need a free GitHub account.

FormUse it when
Supported site changedChatGPT, Claude, Gemini or Grok changed its page and an action stopped working: checkboxes, Select all, Load all older chats, Delete, Archive or Export.
Bug reportSomething else does not work as expected.
QuestionYou want to know how to do something.
Feature requestYou have an idea. Describe the problem first. The extension stays local and asks for few permissions, so some ideas will not fit.
Translation fixA translation is wrong, awkward or missing.

Security problems are different. Do not open a public issue. Use GitHub’s private vulnerability report.

You can also reach the form from the extension: Options, About, Report a problem.

What to include#

  • The site (ChatGPT, Claude, Gemini or Grok) and its address (chatgpt.com or chat.openai.com).
  • Your browser, its version and your operating system, for example “Chrome 150 on Windows 11”.
  • The extension version (the popup header shows it).
  • What you did, what you saw and what you expected. Short steps are best.
  • Which action failed: panel or checkboxes, Select all, Load all older chats, Delete, Archive or Export.
  • The reason text from the result screen, for example Couldn’t find the chat’s menu button or The site refused the request (404). Quote the reason. Leave out the chat title.
  • Whether Fast mode was on and whether turning it off changed anything.
  • The diagnostics from the next section.

Copy diagnostics#

  1. Open the Options page

    Click the toolbar icon, then the sliders button (Settings).

  2. Go to Privacy

    Find the Privacy section.

  3. Click Copy diagnostics

    You see Diagnostics copied. Paste them into a bug report. Paste them into your report.

The text looks like this, with your own values:

AI Bulk Chat Manager 9.0.0
Browser: chrome (Mozilla/5.0 ...)
Interface language: en (setting: auto)
Settings: theme=system, accent=teal, fastMode=true, autoLoad=true, confirmThreshold=20, launcher=false
No chat titles, addresses or other page content are included in this report.

It contains no chat titles, links or page content. Look at it before you paste it anyway.

What never to paste#

Keep these out of public reports

Issues are public. Never paste any of these:

  • chat titles, chat links or conversation text;
  • session cookies, access tokens or API keys;
  • your email address, account details or other personal data;
  • an export file, or the output of Copy report without checking it first. Both contain chat titles.

You do not need any of them. If a screenshot helps, crop it so that no chat titles show, or blur them.

What happens next#

This is a free project kept by one volunteer, so replies are not instant. Reports about a changed site are the most useful, because they point to the exact action that broke. Check the existing issues first, as someone may have reported the same thing.

For anything about privacy, read Privacy and permissions. The developer’s website is www.enaloo.com.
